## Design Philosophy & Tech Stack
The AgriSense-Edge Portal blends design aesthetics from:
- **Apple**: Cinematic hardware reverence, interactive 3D stepped probe schematic, patent pending badge, high-contrast CTAs.
- **Claude / Anthropic**: Editorial warmth, serif typography, academic paper reader, clean paper texture, sticky table of contents.
- **Google DeepMind**: Interactive scientific sandboxes, real-time acreage impact calculator with full FAO-56 Penman-Monteith equation disclosure.
- **Modern IoT Startups**: Linear-style telemetry, dark glassmorphism, dynamic engineering carousel, and interactive Node-RED simulation studio.

### Tech Stack
- **Framework**: React 18, Vite
- **Styling**: Tailwind CSS, Vanilla CSS Glassmorphism
- **Icons**: Lucide React
- **Deployment**: GitHub Pages / Vercel

## Local Development

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build production bundle
npm run build

# Preview production build locally
npm run preview
```

## Features
1. **Live Edge Gateway Beacon**: Real-time indication of on-premises Node-RED gateway connectivity and sub-120ms latency.
2. **Dynamic Engineering Carousel**: 5 auto-advancing slides covering sensor physics, RF telemetry, edge middleware, zero-loss latching, and future drone swarms.
3. **Scroll-Driven Winding Road Pipeline**: 5-stage cyber-physical dataflow from dielectric permittivity to micro-dosed valve actuation.
4. **Node-RED & Kaggle Simulation Studio**: Dual-mode time-series streaming or manual multi-depth sliders with real-time valve state machine and agronomic yield diagnostic engine.
5. **Acreage Impact Calculator**: Dynamic slider (1-1,000 acres) computing liters conserved, kWh saved, and avoided CO₂e with full mathematical formulas.
6. **Dedicated Research Paper Center**: 13-section manuscript reader in Claude editorial style with direct compiled PDF download and print view.
7. **FarmBuddy AI Showcase**: Smartphone mockup and beta invitation registration.
