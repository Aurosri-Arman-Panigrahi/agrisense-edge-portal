## 🌾 Design Philosophy & Features

The **AgriSense-Edge Portal** combines sleek aesthetic paradigms:
- **Apple Hardware Elegance**: Cinematic stepped probe schematic, patent pending badge, high-contrast CTAs, ultra-refined typography.
- **Anthropic / Claude Editorial Depth**: Clean academic paper reader with sticky Table of Contents and direct PDF viewer mode.
- **DeepMind Scientific Rigor**: Interactive scientific sandboxes, real-time acreage impact calculator with full FAO-56 Penman-Monteith equation disclosure.
- **Industrial IoT SCADA Monitoring**: Real-time Node-RED gateway connectivity beacon, Kaggle simulation studio, multi-depth moisture gauges, and hysteretic state machines.

### Key Capabilities
1. **Interactive IEEE Research Paper Viewer**: Full 5-page PDF document viewer with direct jumps to Table I (Page 4) and Section IX-B.
2. **Kaggle Soil Dynamics Simulation Studio**: Real-time multi-depth time-series cycler streaming 10cm, 25cm, and 45cm volumetric water content.
3. **Cyber-Physical Pipeline**: 5-stage visual telemetry flow from capacitive dielectric permittivity to 12V bi-stable pulse latching.
4. **Dynamic Acreage Impact Calculator**: Real-time agricultural savings engine calculating water conservation, energy reduction, and avoided CO₂e emissions.
5. **FarmBuddy™ AI Assistant**: Natural language farming copilot preview for pest alerts and hyper-localized weather forecasts.

## 🛠️ Local Development & Build

```bash
# Clone the repository
git clone https://github.com/Aurosri-Arman-Panigrahi/agrisense-edge-portal.git
cd agrisense-edge-portal

# Install dependencies
npm install

# Run Vite development server
npm run dev

# Build production bundle for deployment
npm run build

# Preview production build locally
npm run preview
```

---

## 🚀 CI/CD & Deployment
This repository is configured with automated GitHub Actions in `.github/workflows/deploy.yml`:
- Every push to `main` automatically builds the React application and deploys to **GitHub Pages**.
- High-resolution PDF artifacts (`AgriSense_Edge_Research_Paper.pdf` and `main.pdf`) are served directly from the root bundle.
